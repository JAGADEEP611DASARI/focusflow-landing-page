# FocusFlow Landing Page

Responsive single-page marketing website for a fictional productivity app called FocusFlow.

## Files
- `index.html` — semantic page structure and sections
- `styles.css` — layout, color palette, responsive breakpoints, and motion
- `script.js` — mobile navigation and demo focus button

## Run in VS Code
1. Extract the ZIP and open the folder in VS Code.
2. Open `index.html` in a browser. You can also install the Live Server extension, right-click `index.html`, and choose **Open with Live Server**.
3. Resize the browser or use DevTools device emulation to test mobile responsiveness.

No build tools or npm packages are required. The Google Fonts link uses an internet connection; system fallbacks are included.
